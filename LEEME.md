# Taller Control — versión conectada a tu propio Supabase

1. En supabase.com crea un proyecto. En SQL Editor ejecuta `supabase/taller_control_base_de_datos.sql`.
2. En Storage crea el bucket privado `evidencias` (si el SQL no lo creó).
3. Copia `.env.example` como `.env` y llena tus datos (Project Settings -> API).
4. Instala y arranca: `npm install` y luego `npm run dev`.
5. Regístrate en `/auth`; el primer usuario queda como Jefe de Taller.
